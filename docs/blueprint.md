# **App Name**: Bharath Edu Portal

## Core Features:

- User Authentication & Session Management: Facilitate secure login for both Staff/Admin (Email/Password) and Students (Roll Number/Password), maintaining user sessions via localStorage for persistence across browser interactions.
- Role-Based Access Control & Routing: Implement a robust routing system that enforces role-specific access, redirecting users based on their authentication status and assigned role (Admin, Teacher, Student) to their respective portal sections.
- Admin Panel Layout & Navigation: Establish the foundational UI for the Admin experience, including a dynamic, collapsible fixed sidebar for navigation and a persistent header with context-aware page titles.
- Student Portal Layout & Navigation: Construct the distinct UI framework for the Student portal, featuring its own simplified fixed sidebar for streamlined navigation and a dedicated header with personalized greetings.
- Module Placeholder Pages: Integrate 'Coming Soon' placeholder pages for all future Admin and Student modules, dynamically rendering module-specific titles, descriptions, and iconography to represent the full application structure.
- Foundational UI Components: Develop and standardize essential UI components such as Avatar circles (displaying initials) and Badge elements for roles or statuses, ensuring consistent visual identity and responsiveness across the application.
- Cross-Platform Responsiveness: Engineer both Admin and Student interfaces to be fully responsive, with sidebars intelligently transitioning to off-screen, drawer-style navigation, accessible via a hamburger menu on smaller screens, and content adapting seamlessly.

## Style Guidelines:

- The application embraces a light color scheme, anchored in principles of education and professionalism. A profound navy blue, '#1E2A4A' (Hue: 221, Saturation: 42%, Lightness: 20%), serves as the primary organizational color, lending gravitas to administrative elements like sidebars and headings. The background is a very light, almost imperceptible grey-blue, '#F5F7FA' (Hue: 210, Saturation: 26%, Lightness: 98%), creating a clean and spacious feel. A dynamic teal, '#0D7C8F' (Hue: 189, Saturation: 80%, Lightness: 30%), functions as a striking accent, highlighting interactive elements and active states, providing a sense of innovation and trust. Additional blues, like '#1A3A5C' and '#0D5C72', are reserved for the student portal's distinct branding, ensuring a coherent yet differentiated user experience. Explicitly, teal is used as an accent color as specified.
- The entire application utilizes the 'DM Sans' sans-serif typeface, imported from Google Fonts, covering weights 400, 500, and 600. This choice offers excellent readability and a modern, versatile aesthetic that is well-suited for both extensive body content and prominent headlines throughout the CRM and student portal. Note: currently only Google Fonts are supported.
- All iconography is drawn from 'lucide-react', ensuring a cohesive, minimalist, and contemporary visual language. Specific icons, including a graduation cap for branding, various chevron directions for UI controls, bell icons for notifications, and logout symbols, will be consistently applied to reinforce usability and clarity.
- The CRM employs distinct layouts for Admin and Student users, each featuring fixed left-hand sidebars for navigation and top headers for context. The Admin sidebar is designed to be collapsible (from 260px to 68px), maximizing content area flexibility, while the Student sidebar maintains a simpler, fixed width (240px to 64px collapsed state if implemented in Phase 2). Content areas dynamically adjust their left margins based on the sidebar's state. For mobile screens (below 768px), both sidebars are initially hidden, accessible through a hamburger menu that triggers a full-height, slide-in overlay, maintaining full content width.
- Subtle and efficient 'all 150ms ease' transitions are integrated into key UI elements to enhance user interaction. This includes smooth transformations for navigation link hover/active states, fluid expansion and collapse of sidebars, and soft loading spinners for login button interactions, providing refined feedback and a polished feel.
